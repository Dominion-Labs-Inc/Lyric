# INTRINSIC-EVENTDRIVEN-01 — intrinsic pursuit runs on events

**What it tests.**
- Each kind of frontier goes to its real closer:
  - knowledge becomes a research goal;
  - capability becomes a competence drive goal;
  - environment gets no goal, because its own reaction closes it.
- A state-changing event triggers one selection cycle, and a burst of events collapses into one cycle.
  There is no timer.
- End to end: a real event drives the real selection cycle, and the cycle reads the pursuit that was
  seeded on the frontier.

**Run** (from the TorinAI folder):

```
./venv_torin/bin/python3 experiments/INTRINSIC-EVENTDRIVEN-01/experiment.py
```

The docstring's `scratchpad/bench_eventdriven.py` is an old path.

**Results.** Printed to the terminal only; no run is saved.
