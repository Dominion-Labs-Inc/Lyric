# INTEGRITY-01 — integrity is coherence, not success

**What it tests.** Integrity is the average of the measured links in the chain
identity → intention → action → outcome, and it is not the same as success.
- A self-initiated success scores about 1.0.
- A failure of the substrate's own strategy lowers it.
- An external failure is a worse outcome, yet leaves integrity higher than a strategy failure.
- With no measured link, integrity is unmeasured (None), not zero.
- Low integrity makes the substrate verify more and replan; high integrity supports engaging.

**Run** (from the Lyric folder):

```
./venv_lyric/bin/python3 experiments/INTEGRITY-01/experiment.py
```
